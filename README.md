
# Sorting Visualizer

An interactive web application that visualizes the Bubble Sort algorithm using animated bars.

## Features

- Generate a random array of 30 numbers.
- Visualize Bubble Sort in ascending order.
- Adjust the sorting animation speed.
- Track the number of comparisons performed.
- Highlight bars during comparisons and after sorting.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Click **Generate New Array** to create a random array.
4. Click **Start Bubble Sort** to watch the sorting process.
5. Adjust the speed slider to change the animation delay.

## Algorithm

Bubble Sort repeatedly compares adjacent elements and swaps them when they are in the wrong order.

- Time complexity: O(n²) average and worst case.
- Auxiliary space complexity: O(1) for the sorting algorithm.
